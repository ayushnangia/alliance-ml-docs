# Resource Allocation Competition

Other languages:

- English
- [français](Resource_Allocation_Competition_fr.md)

The Resource Allocation Competition (RAC) enables faculty members and their research groups to access compute, storage and cloud resources beyond what can be obtained via the [Rapid Access Service](Rapid_Access_Service.md) (RAS).

If you are not sure about which application process is best for your project, please email allocations@tech.alliancecan.ca.

You may also wish to consult the RAC [Frequently Asked Questions](RAC_FAQ.md) and [Technical Glossary](https://docs.computecanada.ca/wiki/Technical_glossary_for_the_resource_allocation_competitions).
